# @quiverdex/api

Quotes, RFQ auctions with signed solver bids, order intake with signature recovery, an SSE stream for solvers, and a `Settled` watcher. `QUIVER_SETTLEMENT` is required. Reference: [docs/api.md](../../docs/api.md). `pnpm e2e` runs the whole system (deploy, API, solver, seller) on an anvil fork of mainnet.
