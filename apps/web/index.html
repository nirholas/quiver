Sign what you want. Solvers fight over how.

Quiver is the first aggregator on Robinhood Chain. One signature places an order that names the least you will accept; solvers compete in a 1.5-second auction to fill it across Uniswap v2, v3 and v4, and the winner earns twenty seconds of exclusivity. QuiverSettlement pulls your tokens through Permit2, runs the winner's route, and reverts unless you receive at least your minimum. No approvals per trade, no MEV surplus left on the table, no admin keys.

How a swap happens

The same shape as UniswapX and CoW, built for a chain whose stablecoin only speaks Permit2.

1 · quote

Aggregate on-chain

Every v2 pair, v3 fee tier and v4 pool for the pair is quoted in one multicall, plus two-hop paths through WETH and USDG, plus a split across the two best venues.

2 · auction

Solvers bid

An RFQ goes to every connected solver. Each returns a signed bid: the buy amount it will guarantee. Best bid wins, and is shown to you next to the raw on-chain quote.

3 · sign

One Permit2 witness

You sign a Permit2 transfer whose witness is the order: sell amount, minimum buy, receiver, deadline, and the winner's exclusivity window. Nothing moves yet.

4 · settle

Contract enforces the floor

The solver submits your order with its route. The contract pulls, executes, measures the buy-token delta, and reverts if it is below your minimum. Unspent input goes back to you.

Solvers

Permissionless. The reference solver ships in the repo and is deliberately beatable.

git clone https://github.com/nirholas/quiver && cd quiver && pnpm install && pnpm -r build
SOLVER_PRIVATE_KEY=0x... QUIVER_API_URL=https://api.quiver.dev pnpm solver
# subscribes to /solvers/stream, bids on RFQs from the on-chain quote minus SOLVER_MARGIN_BPS,
# simulates settle() and fills orders it won (or any unrestricted order)
bid

Signed bids, no stake

A bid is a personal_sign over the RFQ id and amount. Winning costs nothing; failing to fill just hands the order to everyone else when exclusivity lapses.

execute

One UniversalRouter call per route

Inputs are transferred to the router, every hop pays from the router balance, intermediates stay inside it, and the last hop pays the settlement contract. v2, v3 and v4 legs mix freely.

compete

Bring your own edge

Private inventory, off-chain liquidity, cross-venue arbitrage: anything that delivers more than the on-chain quote wins the auction. The contract only cares that the seller's floor is met.

QuiverSettlement

Non-upgradeable, no owner, no allowlist. Trust assumption: Permit2.

settle(Order order, uint256 permitNonce, uint256 permitDeadline, bytes signature, Interaction[] interactions)
  Order { seller, sellToken, buyToken, sellAmount, minBuyAmount, receiver, deadline, exclusiveSolver, exclusiveUntil, appData }
  - reverts unless msg.sender is exclusiveSolver while block.timestamp <= exclusiveUntil
  - pulls sellAmount via Permit2 permitWitnessTransferFrom (witness = hashOrder(order))
  - executes interactions from the contract (Permit2 itself is never a valid target)
  - requires buyToken delta >= minBuyAmount; pays receiver (minus feeBps, 0 at launch); refunds unspent sellToken
  cancel = Permit2.invalidateUnorderedNonces from the seller's wallet

11 unit tests against the real Permit2 bytecode, a fuzz property that a solver can never keep buy tokens from the order it fills, and a fork test that settles a real Uniswap v3 swap on Robinhood Chain. Deploys deterministically to the same address on 4663 and 46630.
